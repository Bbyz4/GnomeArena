# GnomeArena

This project was completed in collaboration with [my teammate](https://github.com/fszlachetka).

## About

GnomeArena is a simple rhythm-based combat game inspired by [Crypt of the NecroDancer](https://store.steampowered.com/app/247080/Crypt_of_the_NecroDancer/)  
Built as a final project for the Object Oriented Programming course at Jagiellonian University in Kraków.

Project was written in Java using the LibGDX framework.

### Main objectives
  - Emphasizing modular design, inheritance and polymorphism, providing a solid understanding of OOP principles
  - Clear separation of gameplay and visual elements, creating a user-friendly graphical interface
  - Designing the game to be easily extendable for adding new gnomes, weapons, items or maps later on

## 🚀 Installation & Setup

### Prerequisites
Before running the project, make sure you have the following installed:

- **Java JDK 11+**
- **Gradle 7+** (or use the included Gradle wrapper)
- **IDE:** Eclipse, IntelliJ IDEA, or any Java IDE with Gradle support

---

### Clone the Repository
```bash
git clone https://github.com/Bbyz4/GnomeArena.git
cd GnomeArena
```

### Build the project
```bash
./gradlew build
```

### Run the desktop version
```bash
./gradlew :desktop:run
```
